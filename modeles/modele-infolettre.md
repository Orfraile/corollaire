MODÈLE D'INFOLETTRE (pour Brevo)
================================

Comment l'utiliser :
1. Dans Brevo, ouvre « Campagnes », puis crée une campagne e-mail (voir le mode d'emploi).
2. Dans l'éditeur, garde le PIED DE PAGE proposé par défaut : il contient le lien de
   désinscription, obligatoire.
3. Recopie la trame ci-dessous dans les blocs de texte, remplace ce qui est entre
   [crochets] et supprime les crochets.
4. Pour un lien : sélectionne le texte, clique sur l'icône de lien et colle l'adresse.
5. Envoie-toi d'abord un message de test, relis-le, puis envoie.

L'adresse d'un article est :
https://orfraile.github.io/corollaire/articles/NOM-DU-DOSSIER/
(NOM-DU-DOSSIER = le nom du dossier de l'article dans src/content/articles/)

Objet suggéré : Corollaire : [titre de l'article]
